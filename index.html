Petunjuk singkat

  1. Isi nama sekolah, tahun ajaran, periode, dan pilih kelas.
  2. Buka menu Data Siswa untuk menambahkan siswa atau mengimpor Excel.
  3. Buka Input Asesmen untuk mengisi skor observasi, unjuk kerja, dan produk.
  4. Buka Rekap Nilai untuk melihat hasil dan catatan tindak lanjut.
  5. Unduh Excel secara berkala sebagai cadangan dan dokumen pelaporan.

Cadangan Data

Data yang dimasukkan tersimpan di penyimpanan lokal browser pada perangkat ini. Untuk memindahkan ke perangkat lain atau mencegah kehilangan data, unduh cadangan JSON dan file Excel secara berkala.

Perhatian: localStorage bukan database online dan tidak otomatis tersinkron antarperangkat. Jangan menghapus data browser sebelum membuat cadangan. File Excel diperbarui melalui proses ekspor, bukan otomatis setiap kali nilai diketik.
